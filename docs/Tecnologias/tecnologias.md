# Tecnologías y herramientas utilizadas

Para el desarrollo del proyecto **LA CHELONAPP** se han seleccionado diferentes tecnologías y herramientas que permitirán construir la aplicación móvil, el sistema web administrativo y los servicios necesarios para su funcionamiento.

La selección de estas herramientas se realizó considerando las necesidades del proyecto, las características de cada tecnología y los conocimientos técnicos de los integrantes del equipo.

## Justificación de las tecnologías

### ![Laravel](https://img.shields.io/badge/Laravel-FF2D20?style=flat-square&logo=laravel&logoColor=white) ![PHP](https://img.shields.io/badge/PHP-777BB4?style=flat-square&logo=php&logoColor=white) Laravel y PHP
Se utilizarán para desarrollar la API REST, procesar las solicitudes, aplicar las reglas de negocio y establecer la comunicación con la base de datos.

### ![Vue.js](https://img.shields.io/badge/Vue.js-4FC08D?style=flat-square&logo=vuedotjs&logoColor=white) Vue 3
Se utilizará para construir la interfaz web administrativa, permitiendo organizar los diferentes módulos y desarrollar una experiencia de uso adecuada para los encargados del negocio.

### ![Ionic](https://img.shields.io/badge/Ionic-3880FF?style=flat-square&logo=ionic&logoColor=white) ![Angular](https://img.shields.io/badge/Angular-DD0031?style=flat-square&logo=angular&logoColor=white) Ionic y Angular
Se utilizarán para el desarrollo de la aplicación móvil dirigida a los clientes. Estas tecnologías permiten crear interfaces adaptadas a dispositivos móviles y consumir los servicios proporcionados por la API.

### ![PostgreSQL](https://img.shields.io/badge/PostgreSQL-4169E1?style=flat-square&logo=postgresql&logoColor=white) ![Supabase](https://img.shields.io/badge/Supabase-3ECF8E?style=flat-square&logo=supabase&logoColor=white) PostgreSQL y Supabase
Permitirán almacenar y administrar la información del sistema mediante una base de datos relacional, manteniendo centralizados los registros de usuarios, clientes, productos y pedidos.

### ![Git](https://img.shields.io/badge/Git-F05032?style=flat-square&logo=git&logoColor=white) ![GitHub](https://img.shields.io/badge/GitHub-181717?style=flat-square&logo=github&logoColor=white) Git y GitHub
Se utilizarán para controlar los cambios realizados en el código, facilitar el trabajo colaborativo y mantener un registro del desarrollo del proyecto.

### ![GitHub Projects](https://img.shields.io/badge/GitHub_Projects-181717?style=flat-square&logo=github&logoColor=white) GitHub Projects
Permitirá organizar las actividades mediante tableros y tareas, asignar responsables y dar seguimiento al estado del trabajo durante cada Sprint.

### ![Postman](https://img.shields.io/badge/Postman-FF6C37?style=flat-square&logo=postman&logoColor=white) Postman
Se utilizará para comprobar el funcionamiento de los endpoints de la API REST, enviando solicitudes y revisando las respuestas obtenidas.

---

## Importancia de las herramientas seleccionadas

El uso de estas tecnologías permitirá desarrollar los diferentes componentes de **LA CHELONAPP** de manera organizada, manteniendo separadas las responsabilidades de la aplicación móvil, el panel administrativo, el backend y la base de datos.

Además, las herramientas de gestión y control de versiones ayudarán a mantener una mejor coordinación entre los integrantes durante el desarrollo de los Sprints.
